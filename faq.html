Frequently asked questions

The questions people actually ask about Conge.

Is this financial advice?

No. Conge shows automated, rule-based checks on public data — it is not financial advice, and it never tells you to buy, sell, or hold anything. Always verify independently before acting on anything it shows.

Does Conge ever ask for my wallet or private key?

No. Conge is entirely read-only. It never requests a wallet connection, a signature, a private key, or a transaction of any kind — it only reads public on-chain and block-explorer data.

Why does a scan sometimes say "Unknown"?

Usually the shared public RPC that Conge's Worker relays through is rate-limited — it's a third-party endpoint shared by everyone using this chain, and it has a tight limit. Conge already retries automatically, at both the Worker and the app level, but under load a check can still come back "Unknown" rather than a real result. This is expected, not a bug — the finding says so directly, and clicking Rescan a little later usually goes through.

Is Conge affiliated with Robinhood?

No. Conge is not affiliated with, endorsed by, or connected to Robinhood Markets, Inc. in any way. It's an independent project that happens to support Robinhood Chain, a network operated by someone else.

Is the code open source?

Yes — the whole site, the risk-scoring logic, and the Cloudflare Worker proxy are public on GitHub.

How is risk level decided?

By a fixed set of transparent, rule-based checks — no model, no hidden scoring. See how it works for the full list of checks and what each one means.

What chain does Conge support?

Robinhood Chain mainnet (chain ID 4663) only, for now. Support for other chains isn't currently planned but could be added later.
