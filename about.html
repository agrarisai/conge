About Conge

What it is, and who's behind it.

Conge is a free, read-only risk scanner for tokens on Robinhood Chain. Enter a contract address and it runs a set of transparent, rule-based checks — holder concentration, ownership, whether selling actually works, and more — using only public on-chain and block-explorer data. It never asks for a wallet connection, a signature, or a transaction; see how it works for the full pipeline.

Conge is a small, independent project — built and maintained by one person, not a company. There's no team page here because there's no team to introduce: just somebody who wanted a fast, honest way to check a token before trusting it, and figured other people on this chain could use the same thing.

Conge is not affiliated with, endorsed by, or connected to Robinhood Markets, Inc. in any way. "Robinhood Chain" is simply the network Conge currently supports — the name belongs to its own operator, not to this project.

The code is open source — see it, read it, or point out a bug on GitHub.
